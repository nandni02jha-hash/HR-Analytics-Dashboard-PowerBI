## Project Overview

This HR Analytics Dashboard was developed using Power BI to analyze workforce demographics, employee retention, promotion eligibility, job satisfaction, and workforce performance.

The dashboard provides HR professionals and management with actionable insights for data-driven decision making.

## Dashboard Pages

### Home Dashboard

Provides an overview of:

- Total Employees
- Gender Distribution
- Promotion Analysis
- Service Years
- Job Levels
- Distance Status

### Action Dashboard

Provides employee-level actionable insights:

- Employees Due for Promotion
- Retrenched Employees
- Employee Analysis

### Detail Dashboard

Provides deeper workforce analysis:

- Department Analysis
- Job Satisfaction
- Overtime Analysis
- Employee Ratings
- Job Role Performance
